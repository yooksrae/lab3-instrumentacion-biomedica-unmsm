# lab3-instrumentacion-biomedica-unmsm
Repositorio del Laboratorio 2 de Instrumentación Biomédica III (UNMSM). Implementación y caracterización experimental de un amplificador de instrumentación de tres op-amps (TL084N, ganancia = 21) para adquisición de biopotenciales y evaluación de rechazo de modo común (CMRR) a 60 Hz.
